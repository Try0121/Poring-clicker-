PORING CLICKER — PROTOTYPE V1

Fonctions :
- Clic/tap sur le Poring pour gagner des Zeny.
- Classes/professions qui produisent automatiquement.
- Prix qui augmentent à chaque achat.
- Sauvegarde locale automatique.
- Gain hors-ligne, limité à 8 heures.
- Prestige avec formes successives.
- PWA installable sur iPhone et Android.

Test sur téléphone :
1. Envoie le ZIP sur Netlify comme pour l'application Eclipse.
2. Ouvre le site.
3. iPhone : Safari > Partager > Ajouter à l'écran d'accueil.
4. Android : Chrome > ⋮ > Installer l'application / Ajouter à l'écran d'accueil.

Organisation :
- index.html : structure + apparence + logique du jeu.
- manifest.webmanifest : nom/icône de l'app.
- service-worker.js : cache/PWA.
- localStorage : sauvegarde de la partie sur l'appareil.

Prototype privé inspiré de Ragnarok Online ; aucun sprite officiel n'est inclus.
